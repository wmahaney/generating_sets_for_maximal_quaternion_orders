# Generating Sets for Maximal Orders in Rational Quaternion Algebras

Code accompanying the paper **"Generating sets for maximal orders in rational quaternion algebras"** by Kirsten Eisenträger, Eyal Z. Goren, Annamaria Iezzi, Harun Kır, Eda Kırımlı, Jonathan R. Love, William E. Mahaney, Jennifer Park, and Maria Sabitova ([arXiv:2610.10139](https://arxiv.org/abs/2610.10139)).

The Magma code tests two things for orders in the quaternion algebra $B_{p,\infty}$:

1. Whether the elements of norm $\ell^k$ generate the order.
2. How well the count $a_{\ell^k}(\mathcal{O})$ of norm-$\ell^k$ elements matches the theoretical bound.

## Repository Structure

- `does_generate.magma`: all Magma code (functions listed below).
- `data/plots/`: data and plots from the experiments.

## Requirements

- [Magma](https://magma.maths.usyd.edu.au/magma/). Use a 64-bit build, because the large-prime phase-change check overflows on 32-bit Magma.

## Usage

```magma
load "does_generate.magma";
SetSeed(1);   // reproducible runs

p := NextPrime(1000); l := 2; k := 5;
max_bound_battery(p, l, k, 1);                    // maximal orders
sweep_check_diameter_generation(100, 500, 2 : progress := true);
```

Conventions:

- `p` is the ramified prime, and `l` is a prime different from `p`.
- Argument order is always `(p, l, k)`.
- `q` is an auxiliary level prime, used only by the `index_q` and `index_q2` classes.
- Every function that takes an order class accepts either the integer `N` or the string label.

## Order classes

Each class is recognised from the reduced discriminant `Discrd(O)`.

| N | Label | Discrd |
|---|-------|--------|
| 1 | `maximal` | p |
| 2 | `index_p` | p² |
| 3 | `index_p2` | p³ |
| 4 | `index_q` | p·q |
| 5 | `index_q2` | p·q² |

## Major functions in `does_generate.magma`

### Normalised bound error

The bound error is

ε = |a_{ℓ^k}(O) − g_{ℓ^k}(O)| / (#Units(O) · 2k · ℓ^((k+2)/2)).

The bound holds exactly when ε ≤ 1.

| Function | Purpose |
|----------|---------|
| `check_bound_error(O, p, l, k)` | Computes ε for one order. It checks that `2*#Enumerate(O,1,1)` equals `#Units(O)`. It logs any ε > 1 to `violations.log`. |
| `hecke_eigenvalue(O, p, l, k)` | Returns the Hecke eigenvalue λ_{ℓ^k}(e) for the genus vector attached to `O`. |
| `order_shape(O, p)` | Classifies `O` from `Discrd(O)`. Returns the class, the level prime, the mass correction factor and the number of genus vectors. |
| `count_prime_power_norm(O, l, k)` | Returns a_{ℓ^k}(O), the number of elements of reduced norm ℓ^k. |

### Generation tests

| Function | Purpose |
|----------|---------|
| `norm_l_power_index(O, l, k)` | Returns the index in `O` of the Z-module spanned by 1 and all elements of norm ℓ^k. |
| `prime_power_norm_generates(O, l, k)` | Returns true if that index is 1. This checks Z-module generation, which is sufficient but not necessary for ring generation, so a false result only means this certificate failed. |
| `diameter_bound_k(p, l)` | Returns the exponent k from the Sebastian–Sebastiano diameter bound. |
| `sweep_check_diameter_generation(p_min, p_max, l)` | Tests whether random maximal orders are generated by norm-ℓ^k elements, with k from the diameter bound. |
| `phase_change_approximation_data(l)` | Returns a prime `p` and exponent `k` at which the heuristic predicts every maximal order is generated. |
| `main_thm_phase_change_check(l)` | Runs that check on a maximal order. It enumerates a very large set. |

### Order construction

| Function | Purpose |
|----------|---------|
| `order_of_type(type, p, q)` | Builds an order of the given class. |
| `eichler_type_order`, `index_p_type_order`, `index_p2_type_order`, `index_q2_type_order` | Build the individual classes. |
| `random_neighbour`, `random_walk` | Randomise an order within its genus by walking ideal steps of prime norm. |
| `random_order_of_type(type, p, q)` | Builds a base order and then randomises it with a walk. |

### Batteries and sweeps

| Function | Purpose |
|----------|---------|
| `bound_error_samples` | Returns ε for several random orders of one class. |
| `max_bound_battery(p, l, k, N)` | Returns the largest ε, the index of the sample attaining it, the number of violations and the full sample list. |
| `bound_test(type, p, l, k : stat)` | Reduces a battery to its mean, max or min. |
| `sweep_max_bound_battery` | Runs the max battery for every prime `p` in a range. |
| `sweep_bound_test` | Sweeps over `p` and over a range of `k`, using the mean, max or min. |
| `sweep_bound_test_worst` | Reports the worst ε over the whole `k` range for each `p`. |

Output is formatted as Python-parsable tuples, with `*_to_file` variants for saving. The commented driver block at the end of `does_generate.magma` has more examples.
